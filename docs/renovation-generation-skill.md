# 装修效果生成 Skill

## 目标

把平面图识别结果转换为可渲染的装修场景，而不是直接生成一张示意图。

## 输入

- 平面图拓扑：外墙、内隔墙、门、窗、房间边界。
- 房间语义：客厅、卧室、厨房、卫生间、餐厅、阳台、通用空间。
- 素材库：每个素材必须包含用途、适用空间、放置规则、AI说明、属性和资源地址。
- 设计风格：如现代自然、奶油风、北欧、工业风。

## 生成流程

1. 建立房屋结构
   - 识别外墙为房屋边界。
   - 识别内墙为隔断。
   - 门窗作为墙体开口，不作为实体墙封死。
   - 2D 坐标映射到 X/Z 平面，Y 轴作为高度。

2. 基础硬装
   - 刷墙：选择 `wall_finish`，应用到室内墙面。
   - 铺地板/瓷砖：根据房间类型选择 `floor_finish`。
   - 吊顶：选择 `ceiling_finish`，建立天花平面和灯位基础。

3. 灯光
   - 选择 `lighting` 素材。
   - 客厅/餐厅以主灯或线性灯为中心。
   - 卧室以柔和点光源为主。
   - 厨房/卫生间增加功能照明。

4. 固定家具与柜体
   - 厨房优先橱柜。
   - 卫生间优先洁具、浴室柜。
   - 卧室优先床、衣柜、床头柜。
   - 客厅优先沙发、茶几、电视柜。

5. 软装与可视化
   - 根据风格补充颜色、材质、装饰。
   - 生成效果图相机位。
   - 生成 VR 全景相机位，输出 2:1 equirectangular 图片。

## 输出

- `scene-assembly-plan.json`
  - 每个房间的装修步骤。
  - 每一步使用的素材 ID。
  - 放置规则。
  - AI 可读说明。
- `3d-config.json`
  - 结构、材质、家具、灯光配置。
- 效果图
  - 普通效果图用于交付页。
- VR 全景图
  - 2:1 图片。
  - 热点和场景切换配置。

## 判断规则

- 不要把所有房间都用同一种家具。
- 厨房、卫生间地面不要默认木地板。
- 没有门窗识别时必须标记为 `needsReview`，避免全封闭空间。
- 素材缺失时输出 `missingAssets`，不要强行生成不合理家具。
